# Native v1.0 evidence

These are original, unmodified screenshots supplied by the user on 2026-11-16, retained with permission as evidence for the v1.0 feature baseline. They predate the visible `1.0.0` version label. They are manual user evidence, not automated test captures. The desktop image includes the user's desktop applications/taskbar; do not reuse it as generic promotional artwork.

## Editor import

The import dialog shows `dist/index.html`, the project name, and the complete built folder contents.

The saved project renders a bundled image and the complete toolbar in the editor. This does not establish desktop taskbar clearance.

## Installed project and native properties

The main window lists Slideshow Studio and exposes its source, timing, transition, shuffle, sizing, color, and controls properties. Their presence does not by itself validate every event or renderer response.

![Installed Slideshow Studio with native property controls](v1.0/native-properties.png)

## Desktop display and known toolbar overlap

The wallpaper renders on the desktop, but the Windows taskbar obscures the lower toolbar. This is a documented deferred usability issue, not a successful toolbar-layout acceptance result.

![Desktop wallpaper with toolbar partly behind the taskbar](v1.0/desktop-taskbar-overlap.png)
